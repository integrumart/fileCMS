# Changelog

All notable changes to FileCMS will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-03

### Added
- Initial release of FileCMS
- Flat-file database system
- Content management (pages/posts)
- User authentication and management
- Admin panel with modern interface
- Default responsive theme
- Markdown support for content
- Plugin system with example plugin
- Theme system
- Security features (CSRF protection, password hashing, XSS protection)
- Clean URL support with .htaccess
- File upload functionality
- Search functionality
- Multi-language support structure
- Installation wizard
- Comprehensive documentation

### Features
- No database required - all content in files
- Upload and use - simple installation
- Modern and intuitive admin panel
- Secure by design
- Fast and lightweight
- Extensible with plugins and themes
- SEO friendly
- Mobile responsive

### Security
- CSRF token protection
- Password hashing with PHP password_hash()
- XSS protection
- Secure file uploads
- Session management
- Protected directories
- Input sanitization
